description: Mobile app for hosting short ranked MVP votes with friends or teams.
---

MVP Vote is an Expo/React Native client where one host opens a lobby and participants cast MVP (and optional loser) votes. Anonymous Firebase Auth identities back lobbies, history, and saved teams in Firebase Realtime Database. There is no separate application backend in this repository.
